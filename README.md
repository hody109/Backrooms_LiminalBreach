# Backrooms: Liminal Breach

Desktop 2.5D Backrooms game inspired by early Doom-era raycasters.

## Run

Double-click `BackroomsLiminalBreach.exe`.

If Windows blocks the unsigned executable, use `START_GAME.bat` as a fallback.

The game is not a website and does not start a local server. It opens a normal desktop window.

## Controls

- W / S: move forward and backward
- A / D: turn
- Q / E: strafe
- Shift: run
- Space or Enter: interact
- R: restart current level
- F11: toggle fullscreen
- Esc: close archive code terminal

The lower-right minimap shows walls, task objects, exits, and your facing direction. Monsters are intentionally hidden from the map.
Each level generates its own ambient loop at runtime: fluorescent office hum, Poolrooms water echoes, Service Storage concrete ventilation, and Red Archive tape hiss. Footsteps also change by surface, including water splashes in Poolrooms and concrete steps in Service Storage.

## Levels

- Level 0: collect three fuses and wake the terminal.
- Level 37: turn valves in the order 2, 4, 1, 3.
- Level 1: find the keycard, flip both breakers, start the generator.
- Level 3: collect tapes and enter the archive code 4132.

After a level task is solved, a mysterious door appears at a random reachable place on the map. Find it and walk into it to transition.
Monsters stalk the maps, wrong puzzle choices can trigger jumpscares, and sanity reaches zero if you stay too close for too long.
